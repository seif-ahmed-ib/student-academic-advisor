# Student Academic Advisor

A course project for **Basic of AI Programming Skills (DSC 311)**.

## Project Overview

The project consists of two connected parts within the Student Academic Advisor domain:

- **Part A:** Fuzzy Rule-Based Expert System
- **Part B:** K-Means Clustering

## Main Goals

- Meet all official project requirements.
- Keep the knowledge base separate from the inference logic.
- Produce explainable expert-system conclusions.
- Analyze student performance groups using K-Means.
- Connect both parts as one coherent academic advising system.

## Current Status

Project initialization and requirements analysis.
